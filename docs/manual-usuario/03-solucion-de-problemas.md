# 4. Solución de problemas y glosario

## 4.1. Acceso y cuenta

| Situación | Qué hacer |
| --- | --- |
| El correo no se admite en el registro | Use su correo terminado en @unillanos.edu.co y compruebe que no tenga espacios ni errores de escritura. |
| La cuenta ya existe | Inicie sesión. Si no recuerda la contraseña, utilice la recuperación en la web. |
| Falta confirmar el correo | Desde el inicio de sesión web, utilice Reenviar enlace y revise el correo institucional, incluida la carpeta de no deseados. |
| El enlace de confirmación no es válido o venció | Solicite otro enlace desde el inicio de sesión web. |
| El enlace de restablecimiento venció o ya se utilizó | Solicite uno nuevo. Es de un solo uso y su vigencia es de 30 minutos. |
| No llega el correo de recuperación | Compruebe la dirección y las carpetas del correo. El mensaje de la pantalla es genérico y no confirma la existencia de la cuenta. |
| No puede entrar con correo y contraseña | Revise sus credenciales o recupere la contraseña. El aviso de credenciales incorrectas no identifica cuál de los dos datos falló. |
| La sesión terminó en otro dispositivo | Inicie sesión de nuevo. Cambiar o restablecer la contraseña puede cerrar sesiones anteriores. |
| Se informa que la cuenta fue reactivada | Acepte el aviso para continuar. Revise las inscripciones; las canceladas no se reactivan automáticamente con la cuenta. |
| No aparece una opción de administración | Compruebe el rol y use la web. La gestión de categorías, organizadores y actividad corresponde al Administrador. |

## 4.2. Eventos e inscripciones

| Situación | Qué hacer |
| --- | --- |
| No encuentra un evento | Limpie los filtros y compruebe la fecha. Los cancelados y los que ya iniciaron no aparecen como nuevas actividades en la exploración ordinaria. |
| La fecha Desde es posterior a Hasta | Corrija el rango antes de continuar la consulta. |
| No quedan cupos o se perdió el último cupo durante la inscripción | Revise otros eventos o vuelva a consultar la disponibilidad si alguien cancela. |
| Ya tiene una inscripción activa | Abra Mis inscripciones o Inscripciones para consultar su entrada. |
| No puede inscribirse en un evento propio | El organizador gestiona ese evento; puede participar como inscrito en actividades de otros organizadores. |
| No puede cancelar la inscripción | Compruebe que esté activa, sea suya, no tenga asistencia y el evento no haya iniciado. |
| No aparece el QR | Compruebe que la inscripción esté activa y que no haya terminado el día del evento. |
| No puede editar o cancelar un evento | Compruebe que sea suyo o tenga rol Administrador, que no esté cancelado y que aún no haya iniciado. |
| No puede reducir el cupo máximo | El cupo máximo debe cubrir al menos las inscripciones activas actuales. |
| No hay categorías disponibles al crear el evento | Solicite al Administrador que cree o active una categoría. |

## 4.3. Asistencia, documentos e instalación

| Situación | Qué hacer |
| --- | --- |
| La web no tiene un escáner | El organizador registra la asistencia desde la APK, entrando al evento propio, Inscritos y asistencia y Escanear QR de entrada. |
| La cámara no se abre | Conceda el permiso desde la aplicación o los ajustes del teléfono. También puede ingresar el código manualmente. |
| El QR no se reconoce | Abra la entrada vigente, manténgala completa y utilice el código escrito si necesita validación manual. |
| Se rechaza una asistencia duplicada | Consulte el listado para comprobar el primer registro. No se genera una segunda asistencia. |
| El registro de asistencia pierde conexión | Restablezca internet y consulte el listado antes de volver a validar. |
| No puede descargar un certificado | Compruebe que el evento sea certificable, que haya iniciado, que conserve la inscripción activa y que su asistencia esté verificada. |
| La APK no se instala | Compruebe que descargó EventU-v1.0.0.apk desde la release y que Android permite instalar desde la aplicación con la que abrió el archivo. Si sigue fallando, conserve el mensaje exacto y consulte al responsable del programa. |
| El PDF no se abre | Compruebe que dispone de una aplicación para abrir PDF. En Android, use las opciones del sistema para guardarlo o compartirlo. |
| Los datos no cargan | Compruebe la conexión a internet y vuelva a abrir la pantalla. Si el problema continúa, comunique al responsable la pantalla y el mensaje observado. |

## 4.4. Glosario

| Término | Significado |
| --- | --- |
| APK | Archivo de instalación de la aplicación Android. |
| Categoría activa | Clasificación que puede seleccionarse al crear un evento. |
| Evento publicado | Evento disponible según sus condiciones de fecha y cupos. |
| Evento cancelado | Actividad cuya cancelación impide nuevas inscripciones y cancela las activas. Se conserva el historial. |
| En curso / finalizado | Indicaciones de tiempo de la actividad. No son instrucciones para pulsar un botón de finalización. |
| Inscripción activa | Reserva vigente de un participante para un evento. |
| Inscripción cancelada | Reserva que dejó de estar activa; su registro histórico se conserva. |
| Entrada QR | Código único de una inscripción utilizado por el organizador para validar el acceso. |
| Asistencia registrada | Confirmación guardada tras validar correctamente una entrada. |
| Evento certificable | Evento configurado para entregar certificados a inscritos con asistencia verificada. |
| Reporte PDF | Documento de participantes y asistencias del evento, generado por el Organizador o el Administrador. |
| Certificado PDF | Documento individual que acredita la asistencia de un participante. |
| Registro de actividad | Consulta de operaciones de la plataforma, disponible para el Administrador y de solo lectura. |
